Under the hood

How QuestHub is built

A modern hybrid stack: structured database + vector search + AI, fed by safe APIs instead of bulk scraping.

Frontend

Next.js / React, mobile-first, accessible, no tracking.

API Layer

FastAPI (Python) with auth, content, chat, and moderation services.

PostgreSQL

Curated games, facts, guides, tags, users — the source of truth.

Vector DB

Pinecone / Weaviate stores embeddings for fast semantic search.

Redis Cache

Trending questions, rate limiting, session state.

RAG Chat

Embed → retrieve → moderate → answer with Claude or GPT.

Ingestion

Wikipedia + Reddit APIs, scheduled jobs, no bulk scraping.

Moderation

OpenAI moderation API + keyword filters, kid-safe by default.
